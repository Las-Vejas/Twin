# Twin
A macropad for both your computer and Home Assistant.

I built this because I wanted a central place to control both my home/room, and my computer at the same time.
This device switches between the Home Assistant mode and PC mode with a click of a button and you receive all the feedback through the 25 leds on board.

This macropad contains:
- 14 underglow leds
- 11 switches (with leds underneath)
- RP2040
- ESP32-C6
- 1 rotary encoder
